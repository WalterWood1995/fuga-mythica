德语怎么造词

德语的长词不是背出来的,是拼出来的。下面这张图是全部零件;点任一个跳到它的细节。 最后一节把所有零件串成一条完整的故事:从三个辅音,一路造到 Unverbindlichkeit。

① 骨架:辅音是身份证,元音只是衣服

印欧语的词根，辅音序列才是身份,元音是可换的。德语把这一点保留得最彻底: b–n–d 这副骨架,不管元音换成什么,意思都绕着「捆、系」转。

骨架换上不同元音造出来的词
b–n–di / a / ubinden 捆 · das Band 带子 · der Bund 联盟
st–nde / a / ästehen 站 · der Stand 状态 · ständig 不断的
g–be / a / igeben 给 · die Gabe 天赋 · das Gift 毒(原义「给出去的东西」)
sp–che / a / usprechen 说 · die Sprache 语言 · der Spruch 箴言

所以查一个陌生的长词,先在心里把元音抹掉,只看辅音——十次里有七次能认出熟词。

② 换元音:Ablaut,德语最值钱的机制

这不是随机变化,而是印欧语留下的元音交替(Ablaut),在德语里凝固成强变化动词的七类。 动词三态一换完,后面每加一个后缀就是一个新名词。

记法:记一个三态,等于记一串名词。binden / band / gebunden 一背完,Band、Bund、Bündnis、Verband、Bindung 全部到手。

③ 加前缀:方向与态度

前缀不改变词根的意思,只给它加方向(出、进、上、下)或态度(做坏了、做到底、做没了)。 分两类,这个区分决定句子怎么排:

不可分前缀 be- ge- er- ver- zer- ent- miss- —— 永远粘着词根,重音不在它身上,过去分词不加 ge-:verstehen → verstanden。

可分前缀 auf- aus- ein- an- ab- mit- nach- vor- zu- —— 说话时被甩到句尾:Ich stehe um sechs auf. 过去分词把 ge- 夹在中间:aufgestanden。

数字是本词库里实际出现的词数。ver- 和 be- 两个就管着五百多个词——先吃这两个最划算。

④ 加后缀:决定词性,顺便决定性别

后缀是德语给你的免费礼物:它把词性写在脸上,而名词后缀几乎锁定阴阳中性——记住后缀就不用背 der/die/das。

三条可以当公式用的规律

· -ung / -heit / -keit / -schaft / -ei / -ion / -ität → 一律 die(阴性)

· -chen / -lein / -tum / -nis → 一律 das(中性,所以 das Mädchen 是中性,跟女孩无关)

· -er / -ling / -ist / -or / -ent → 一律 der(阳性);加 -in 变阴性

⑤ 复合:德语长词的真正来源

本词库里 — 个词是复合词——把两个独立的词直接焊在一起。规则只有一条: 最后一截决定一切(词性、性别、复数);前面的都是修饰。

die Arbeit + -s- + der Platz → der Arbeitsplatz 工作岗位

是 der,因为末尾是 Platz;意思是「一种 Platz」,不是「一种 Arbeit」。倒过来 der Platzarbeiter 就完全是另一回事。

中间那个粘合剂:Fugenelement

两半之间常插一个小零件,纯粹是为了顺口,没有意思。本库中出现 — 次。

最好用的经验:前件若以 -ung / -heit / -keit / -schaft / -tum / -ling 结尾,后面几乎一定插 -s-(Zeitungsartikel、Freiheitskampf、Wissenschaftsbuch)。

⑥ 框式与外来层:剩下的两块拼图

框式 ge-…-t:前后一起夹住词根

过去分词不是加一个缀,而是前后同时加:ge-mach-t、ge-sproch-en。 这解释了两件事:不可分前缀的动词没有 ge-(verkauft,因为 ver- 已经占了那个位置);可分前缀的动词把 ge- 夹在中间(eingekauft)。

外来层:拉丁与希腊的那一套

德语有一整套平行的外来构词零件,规则更整齐——因为它们是成套借来的:

外来后缀对应的德语土产例
-ion / -ation-ungdie Information · die Organisation(一律 die)
-ität / -tät-heit / -keitdie Aktivität · die Realität(一律 die)
-ieren-enorganisieren · analysieren(弱变化,分词 -iert,不加 ge-)
-ist / -ent / -or-erder Journalist · der Student · der Motor(一律 der)
-iv / -al / -ell / -ös-ig / -lichaktiv · normal · offiziell · nervös

拉丁前缀也照搬:in-(否定)、re-(再)、de-(去)、prä-(先)、trans-(跨)。同一个概念常有土产和外来两个词:Fernsprecher / Telefon。

⑦ 一条完整的故事:从三个辅音到 Unverbindlichkeit

同一套动作,换一副骨架再走一遍

st–nd:骨架「立」→ 换元音 stehen / stand / gestanden → 加前缀 verstehen 懂(「把它立起来」) → 加后缀 Verständnis 理解 → 复合 Selbstverständlichkeit 理所当然。五步,五个词,一个骨架。

怎么用这张图查一个陌生的长词

① 从右边看起——最后一截决定词性和性别。② 削掉认得的后缀。③ 削掉前缀。 ④ 剩下的东西抹掉元音,只看辅音,去找熟悉的骨架。⑤ 把意思按「前缀的方向 + 骨架的意思 + 后缀的词性」拼回去。

练一个:Unverbindlichkeit → un + ver + b(i)nd + lich + keit → 「不 + 使连上 + 的 + 性质」= 不具约束力。图里第 8 步就是它。
